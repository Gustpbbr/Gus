# Arquitetura — ponto de entrada

**Tipo:** biblioteca de métodos, referências e protocolos reutilizáveis. **Repositório público.**

## Para uma conversa nova de IA
1. Confirmar acesso ao repositório e ler este arquivo.
2. Consultar [PROTOCOLO-DE-ENTRADA.md](00_SISTEMA/PROTOCOLO-DE-ENTRADA.md) antes de orientar escrita, catalogação ou mudanças.
3. Consultar o README do módulo desejado; listar diretórios de forma determinística antes de alegar que o catálogo inteiro foi lido.
4. Distinguir informação observada, documentada, inferida, pendente, aprovada e substituída.
5. Não tratar uma sugestão, print ou simulação como decisão aprovada, execução concluída ou ficha técnica validada.
6. Nunca publicar dados pessoais, imagens internas, plantas detalhadas, contratos, endereços completos ou arquivos privados.
