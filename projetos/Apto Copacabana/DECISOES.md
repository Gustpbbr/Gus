# Registro de decisões — Apto Copacabana

Este arquivo é o histórico de decisões **confirmadas** do projeto, não um depósito de sugestões da IA.

**Estado inicial em 2026-11-08:** nenhuma nova decisão registrada nesta estrutura.

## Modelo de decisão

### DEC-AAAA-NNN — [título]

- **Data:** AAAA-MM-DD
- **Serviço/ambiente:** ...
- **Decisão confirmada pelo usuário:** ...
- **Alternativas consideradas:** ...
- **Motivo e critérios:** ...
- **Status:** proposta | confirmada | substituída | cancelada
- **Substitui:** DEC-... (se aplicável)
- **Fontes de suporte:** links de pesquisa/documentação não sensíveis
- **Próxima ação:** ...

## Princípios

1. Não presumir que uma simulação, imagem ou sugestão virou decisão.
2. Uma mudança não apaga o histórico: a decisão anterior passa a **substituída**.
3. Não armazenar dados particulares do apartamento no repositório público.
4. O GitHub documenta, mas não executa contratações nem envia mensagens.
