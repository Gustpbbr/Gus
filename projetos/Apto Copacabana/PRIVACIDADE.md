# Segurança e privacidade — Apto Copacabana

**Atenção:** este espaço está no repositório **público** Gustpbbr/Gus.

## O que PODE ficar aqui

- Procedimentos gerais, checklists, critérios técnicos, templates.
- Categorias genéricas de serviços.
- Links públicos de empresas e páginas de fabricantes.
- Resumos não sensíveis de pesquisa, com data e fonte.

## O que NÃO deve ficar aqui

- Endereço completo, número do apartamento ou dados que facilitem identificar o imóvel.
- Imagens internas, planta detalhada, informações de acessos, fechaduras e segurança física.
- Dados pessoais, contatos pessoais, contratos, notas fiscais, documentos, cobranças e pagamentos.
- Senhas, tokens, chaves de API e credenciais de qualquer serviço.
- Conversas privadas, propostas contendo dados pessoais e informações clínicas.

## Caminho recomendado

Se a proposta é realmente usar GitHub como **segundo cérebro completo** do apartamento, criar um **repositório privado separado** e mover a estrutura de acompanhamento para lá antes de registrar detalhes de fornecedores, visitas, preços, documentos e obras.

Um repositório público pode ser clonado por terceiros. Apagar um arquivo ou torná-lo privado depois não garante apagar cópias já obtidas. Não depender apenas do .gitignore para proteger dados já versionados.

## Conector ChatGPT ↔ GitHub

- O usuário deve manter o GitHub conectado ao ChatGPT.
- Acesso de leitura em nova conversa depende da disponibilidade do conector e do pedido/contexto; um arquivo no GitHub **não configura automaticamente** o comportamento do ChatGPT em novas abas.
- Para confiabilidade, manter nas Instruções Personalizadas uma referência explícita ao caminho do README do projeto.
- Escritas no GitHub devem ser feitas somente quando o usuário solicitar e com verificação do arquivo após a operação.
