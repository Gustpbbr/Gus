# Apto Copacabana — segundo cérebro do apartamento

**Estado:** espaço inicial de organização, criado em 2026-11-08.
**Repositório:** Gustpbbr/Gus (PÚBLICO). **Este diretório contém apenas instruções e modelos não sensíveis.**

## Objetivo

Centralizar procedimentos, pesquisas, serviços, fornecedores, orçamentos, decisões, cronogramas e manutenção do apartamento de Copacabana, no Rio de Janeiro, de forma consultável e versionada.

O GitHub guarda a documentação; o ChatGPT ajuda a pesquisar, interpretar, comparar e atualizar informações **somente quando tiver acesso ao conector GitHub**. Não presumir que uma conversa nova leu este repositório.

## Ponto de entrada

Quando o usuário pedir **"preciso fazer orçamentos"** ou outro serviço para o apartamento:

1. Ler **[PROTOCOLO-ORCAMENTOS.md](PROTOCOLO-ORCAMENTOS.md)** integralmente antes da pesquisa, se o GitHub estiver acessível.
2. Consultar **[ORCAMENTOS-PREPARADOS.md](ORCAMENTOS-PREPARADOS.md)** ANTES de pesquisar: se o serviço já possui contatos prontos, entregar os links salvos e não refazer a pesquisa.
3. Consultar **[PAINEL-SERVICOS.md](PAINEL-SERVICOS.md)** para evitar repetir trabalhos e aproveitar critérios já definidos.
4. Identificar serviço, localização e especificações já conhecidas. Perguntar apenas dados essenciais ainda ausentes.
5. Se NÃO houver orçamento preparado, pesquisar na web, verificar fontes e montar opções com links do site/Instagram e WhatsApp pré-preenchido.
6. Depois que o usuário enviar as respostas de orçamento, organizar a comparação; só registrar no GitHub quando ele solicitar a atualização.
7. Registrar decisões em **[DECISOES.md](DECISOES.md)**, sem inventar escolhas nem escrever dados privados neste repositório público.

**Gatilho já preparado:** "quero o orçamento pro gás" → consultar ORCAMENTOS-PREPARADOS.md e servicos/gas/ORCAMENTO-GAS-2026-11-09.md, apresentar links prontos.

**Importante:** nenhum arquivo no GitHub obriga automaticamente o ChatGPT a consultá-lo em toda nova conversa. A regra pode ser reforçada por Instruções Personalizadas ou pelo texto inicial acima. A consulta também depende do conector GitHub estar disponível.

## Convenções

- Evidência antes de afirmação: distinguir verificado / divulgado / não verificado.
- Nunca inventar contato, site, perfil, disponibilidade, preço ou avaliação.
- Um fornecedor só conta como opção distinta quando não é duplicata de outro.
- Nenhum envio de mensagem sem ação do usuário.
- Preservar histórico e data de revisão; marcar informações antigas como pendentes de nova verificação.
- Diferenciar documentação do apartamento de procedimentos executáveis e de dados sensíveis.
